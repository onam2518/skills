# 기획 문서 작성·검수

읽는 사람이 대상·조건·행동·결과를 쉽게 이해하고, 최신 결정과 실제 확인 범위를 구별할 수 있는 문서의 작성·검수

## 적용 우선순위

1. 사용자의 최신 명시 지시와 해당 문서의 지정 양식
2. 사실·수치·조건·예외·미확정 사항과 보존할 원문
3. 이 스킬의 문서 구성·표현·서식 기준
4. 일반 문장 교정 제안

- 특정 프로젝트의 기능·정책을 다른 문서의 기본 정책으로 전용하는 처리 금지
- 검수 요청에는 문제·근거·수정안 제시, 작성·수정 요청에는 해당 대상의 실제 수정과 저장 결과 확인
- 일반 문장 교정을 이유로 표의 의미·제품 결정·기능 지원·검증 결과를 바꾸는 처리 금지

## 필요한 자료

- 모든 기획서: [문장·구조·서식](references/document-standard.md)
- 기존 문서 개편·동시 편집·이관: [의미 보존과 변경 절차](references/preservation-workflow.md)
- 도식 또는 검토용 시트 연결: [도식·시트와 근거의 역할](references/artifact-roles.md)
- 최종 검수: [검수 체크리스트](references/final-review.md)
- 작업 시작에 필요할 때: [작성 설계표](templates/writing-plan.md)
- 개편과 마지막 저장 확인에 필요할 때: [변경·검수 기록](templates/review-record.md)

## 핵심 원칙

- 상위 문서는 목적·범위·핵심 결정·흐름과 상세 문서 링크 중심의 구성
- 상세 기준마다 하나의 기준 위치 지정, 다른 곳에는 요약과 정확한 참조 배치
- 요약·중복 정리 후에도 필수 조건·예외·수치·미결 사항 유지
- 실행에 중요한 경고는 해당 본문에 짧게 표시, 뒷받침 자료는 접힌 Appendix로 연결
- 비개발자에게 익숙한 한국어 우선, 꼭 필요한 기술 용어만 쉬운 뜻·각주로 연결
- 제목을 제외한 설명은 의미 단위별 불릿, 조건·예외는 실제 하위 불릿
- 본문·목록·표 설명은 명사 또는 명사구 종결, 종결 마침표 제외
- 사용자 입력·UI 문구·직접 인용·코드·프롬프트·과거 기록은 원문 보존
- 큰 영역 앞 빈 문단 2개, 하위 소제목 앞 1개, 직접 이어지는 부모·첫 자식 제목 사이 0개
- H2 같은 기술 태그나 정수 번호만으로 의미상 큰 영역을 판정하는 처리 금지
- 목차는 3단계까지 연결되는 자동 목차, 문서 이력은 접힌 영역의 기본 변경 이력 기능
- 도식은 보이는 미리보기와 실제 편집 가능한 draw.io 원본을 함께 제공
- Appendix의 자료·용어·사례·이전 본문은 각각 접힌 영역, 컨테이너의 고유 내용은 확인된 하위 기준 위치로 옮긴 뒤 본문 비움
- 최신 저장본의 사용자 수정과 이전에 확정한 의미 기준을 함께 대조
- 내용·구조·저장 후 재조회·미리보기 이미지·실제 서비스 화면의 검수 범위를 각각 보고

## 작성·수정 절차

1. 대상과 최신 자료 확인
   - 상위·하위 문서의 역할, 원문 버전, 사용자 변경, 현재 기준과 과거 기록의 구분
   - 확정 결정·제안·문서상 구현 보고·직접 측정·미확인의 구분
2. 보존할 의미와 기준 위치 정리
   - 필수 조건·예외·수치·입력 예시·미결 항목을 변경 대조표에 기록
   - 같은 내용의 기준 위치와 요약·참조 위치 지정
3. 내용 편집
   - 독자의 질문 순서로 대상·조건·행동·결과 설명
   - 중복 제거 전 고유한 조건과 예외의 이동 위치 확인
4. 문장과 서식 적용
   - 모든 설명 문단을 하나씩 점검해 명사구·불릿·계층 정합 확인
   - 개요·안내 패널·상단 참조·접힌 현행 설명도 점검 대상에 포함
   - 표·도식·각주·제목·링크·여백의 같은 역할에 같은 규칙 적용
5. 저장 전 대조
   - 최신 저장본을 다시 읽고 변경분과 확정 결정의 충돌 확인
   - 오래된 초안으로 최신 편집을 덮거나, 최신본에 빠진 확정 내용을 무조건 그대로 따르는 처리 방지
6. 마지막 저장 후 검증
   - 저장된 내용을 다시 읽어 필수 기준·고유 문장·구조·링크·파일 참조 확인
   - 실제 화면을 확인한 경우만 화면 검수 완료로 기록
   - 확인하지 않은 기능 실행·배포·모델 시험·시트 가져오기를 완료로 표현하는 처리 금지

## 형식별 적용

- 대상 형식에서 지원되는 목차·접기·여백·편집 원본 기능을 사용
- 해당 기능이 없는 형식에서는 의미와 원본을 보존하는 대체 구성과 한계를 명시
- 기능 지원을 꾸며내거나 서식만을 위해 원문을 훼손하는 변환 금지
- 도식·시트 등 요청에 없는 산출물 검수 항목은 해당 없음으로 처리

## 완료 기준

- 요청 대상에 적용할 기준의 누락 없음
- 필수 의미의 변경 전후 대응과 기준 위치 확인
- 마지막 저장 버전의 재조회 및 확인 범위 기록
- 실제 화면 확인이 없으면 그 한계를 명시한 결과 보고
- 문제를 찾지 못했을 때 임의의 개선안·점수·통과율 추가 금지
