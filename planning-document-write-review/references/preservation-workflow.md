# 의미 보존과 변경 절차

## 변경 전 대조 대상

- 문서·페이지 식별자, 제목, 현재 버전과 시각
- 원래 본문의 고유 조건·예외·부정·우선순위·단계·수치·기한·시간대
- 사용자가 직접 수정한 담당 정보·표현·링크·제목
- 사용자 확정 결정과 아직 미결인 내용
- 표의 행열 대응, 링크 대상, 댓글·각주 연결, 도식·첨부 참조
- 별도 보존할 코드·UI 원문·과거 정책·실측 기록

## 최신본과 확정 내용의 동시 보존

최신 버전이라는 사실은 모든 내용이 최신 결정과 정합하다는 뜻이 아님

1. 저장 직전 현재 문서를 다시 읽고 직전 검토본과 차이 확인
2. 새 사용자 표현·담당자·링크는 필요한 수정 범위 밖에서 유지
3. 이전 확정 조건이 최신본에서 누락되거나 반대로 바뀐 경우 별도 차이로 기록
4. 최신 명시 결정이 명확하면 그 결정에 맞춰 최소 수정
5. 최신 의도가 불명확한 충돌은 확정된 것처럼 조용히 덮지 않고 충돌 내용을 제시
6. 저장 후에는 초안과의 일치뿐 아니라 확정 조건의 실제 존재도 재확인

## 요약·중복 제거·이관

- 원문에만 있던 조건이 새 본문이나 연결된 기준 문서 중 어디에 남는지 대조
- 동일 문장·표의 중복은 한 번으로 정리하되 고유 예외와 근거는 유지
- 공통 정책과 기능 지원, 저장 성공과 실제 적용, 기록 보관과 자동 재사용처럼 서로 다른 축의 합치기 금지
- 특정 구현 보고를 운영 배포·실제 사용자 효과의 근거로 확대하는 처리 금지
- 설계 가설·제안·문서 확인·직접 관찰·미확인을 각각 명시
- 수치·대조 사례·정확한 안내 문구를 대표 예시 하나로 바꾸며 의미를 잃는 축약 금지
- 원문 예시가 담당 상세 문서로 이동했으면 고정 식별자 또는 구체 링크로 추적 가능하게 유지
- 상세 설명을 위키로 옮기면 해당 기준이 실제 저장된 페이지에 존재하는지 확인한 뒤 링크 연결

## 좁은 수정의 범위

- 문장 교정: 의미·조건·수치·지원 상태 유지
- 서식 정합: 설명 단위·계층을 유지한 불릿·번호·여백 적용
- 구조 개편: 기준 위치와 이동 대조표 작성, 고유 내용의 누락 점검
- 원문 보존: 현재 적용 기준과 역사 기록의 명확한 구분

## 실제 실패를 막는 확인

| 놓치기 쉬운 지점 | 확인 방법 |
| --- | --- |
| 개요와 패널에 남은 일반 설명 문단 | 현행 설명 문단 전체를 확인하고 제목·표 셀·파일 표시·인용 예외와 구분 |
| 최신 편집본에서 사라진 확정 조건 | 최신본 비교와 별도로 확정 의미 대조표의 각 항목 존재 확인 |
| 압축 과정에서 빠진 미결 사항 | 조건·예외·미결을 독립 항목으로 대조 |
| 본문은 최신인데 도식은 과거 조건 | 본문·미리보기·편집 원본을 같은 기준으로 비교 |
| 존재하지 않는 상세 절 링크 | 저장 후 실제 제목·절·대상 페이지 확인 |
| 과거 보관본이 현행 판단을 덮는 검색 결과 | 현행부와 역사부를 구분해서 검사 |
| 내부 식별자 변화만으로 손상 단정 | 표시 내용·구조·댓글 연결·파일 연결을 기준으로 확인 |
| 화면 오류를 저장 변환 문제로 추정 | 실제 화면과 저장 구조를 함께 대조한 뒤 원인 판단 |
