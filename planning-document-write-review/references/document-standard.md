# 문장·구조·서식

## 문서 역할

- 기본 흐름: 개요 → 상세 기획 → Appendix
- 상위: 대상·목적·범위·핵심 결정·전체 흐름·상세 링크
- 하위: 해당 역할의 조건·예외·화면·상태·검증·근거
- 동일 기준을 여러 문서에 완전 복제하기보다 기준 문서 한 곳과 짧은 참조 사용
- 지정 참고 문서는 배치·서식의 참고로만 사용, 담당자·정책·수치·서비스 사실의 복사 금지
- 담당자·참조는 대상 문서 또는 사용자가 지정한 최신 근거에서 확인된 정보만 사용
- 하위 문서를 모으기 위한 컨테이너는 고유 본문을 검증된 하위 기준 위치로 먼저 이관하고 링크 확인 후 본문 없이 구성

## 문장과 불릿

- 1차 독자가 이해할 수 있는 대상·조건·행동·결과 우선
- 설명 없는 전문 용어·추상 명사 나열·불필요한 번역투 축소
- 같은 개념의 본문·표·도식·각주 이름 통일
- 필수 기술 용어는 첫 등장에 쉬운 뜻 또는 각주 표식 제공
- 각주 번호의 중복·끊김·자기참조 점검, 상세 용어집은 접힌 Appendix에 배치
- 즉시 이해해야 할 경고나 핵심 개념은 접힌 용어집만 보게 하지 않고 본문에 짧게 설명

명사구 종결 예시

| 피할 표현 | 문맥을 보존한 표현 |
| --- | --- |
| 현재 지원하지 않음 | 현재 미지원 |
| 확인이 필요함 | 지원 여부의 추가 확인 필요 |
| 상태를 확인한 뒤 적용함 | 현재 상태 확인 후 지정 조건의 적용 |
| 저장하지 않음 | 저장 금지 / 저장 대상에서 제외 / 현재 저장 미지원 중 실제 의미에 맞는 표현 |

- 어미만 기계적으로 삭제하지 않고 조사·호응·부정 의미까지 재작성
- ‘책임·포함·게임’ 같은 정상 단어의 부분 문자열을 일괄 삭제하는 처리 금지
- 한 불릿에는 하나의 의미 단위, 여러 독립 원칙은 별도 상위 불릿
- 조건·예외·예시는 적용되는 상위 원칙 바로 아래 실제 중첩 목록으로 구성
- 바로 뒤 목록이라는 이유만으로 무조건 하위 계층으로 넣지 않고 의미 관계 확인
- 본문 설명의 종결 마침표 제외, URL·버전·번호·소수점·식별자 안의 마침표 유지
- 패널 안의 설명과 상단 참조 설명도 일반 문단으로 빠져 있지 않은지 점검
- 표 셀은 같은 역할끼리 일반 문단/불릿·줄바꿈 형식 통일, 행열·병합·너비·색상과 조건 관계 유지

원문 유지 대상

- 실제 화면 안내·오류 메시지·사용자 입력·직접 인용
- 코드·프롬프트·실제 필드명·분류값·식별자
- 과거 기록·시험 입력·관찰 결과·증거 원문

## 제목·목차·여백

- 소제목은 `1. 소제목`, 하위 계층은 `2.1`, `2.2` 형태 유지
- 기존 번호와 참조 앵커는 가능한 한 유지, 번호 변경 시 관련 링크도 함께 갱신
- 문서 제목의 `001` 같은 접두 번호는 해당 프로젝트 관례가 있을 때만 적용
- 자동 목차는 3단계까지 링크 연결, 수동으로 복제한 목차와 혼용 방지
- ‘문서 히스토리’는 접힌 영역 안의 서비스 기본 변경 이력 기능 사용
- 기본 이력 기능이 없는 형식에서는 가능한 대체 방식과 한계를 명확히 기록

| 의미상 다음 영역 | 앞의 빈 문단 수 |
| --- | ---: |
| 개요·상세 기획·Appendix 같은 큰 영역 | 2 |
| 그 아래 번호/비번호 소제목 | 1 |
| 부모 제목 다음에 본문 없이 바로 오는 첫 하위 제목 | 0 |

- 여백 단위는 내용 없는 문단, 줄 간격이나 제목 스타일의 시각적 여백과 구분
- 제목 태그만으로 2칸 규칙을 강제하는 처리 금지
- 제목 사이에 본문·표·목록이 있으면 직접 부모-첫 자식 예외가 아닌 하위 영역 기본 간격 적용
- Markdown의 여러 개행이 실제 빈 문단 여러 개로 표시된다고 가정하는 처리 금지

## Appendix와 본문 경고

- 용어·근거·사례·이전 문서 등 모든 Appendix 내용은 구역별 접기
- 실행을 좌우하는 조건·예외·위험·미확정 사항은 관련 본문에서 확인 가능한 짧은 문구로 유지
- 의미 있는 이전 본문은 날짜·기준 버전을 붙인 보존 구역으로 이동
- 이전 본문을 보관할 때 그 안의 이전 보관본을 재귀적으로 복제하는 방식 금지
- 기존 역사 보존본은 유지하면서 새로 보관할 현행 본문만 추가
- 편집 과정의 설명·변경 자랑·반복 안내·작업 일지는 본문에서 제외
- 실제 제품의 결정·제약·검증 한계와 편집 작업 설명을 혼동하는 처리 금지
