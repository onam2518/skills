# 최종 검수 체크리스트

각 항목은 통과·수정 필요·미검증·해당 없음으로 구분, 요청에 없는 산출물의 생성까지 검수 조건으로 확대 금지

## 내용

- [ ] 문서 역할과 기준 위치의 명확성
- [ ] 필수 조건·예외·미결·수치·우선순위·단계·시간대 보존
- [ ] 최신 사용자 편집과 확정 결정의 동시 대조
- [ ] 원래 고유 문장의 새 위치와 링크 확인
- [ ] 제안·문서상 보고·직접 관찰·미확인의 구분
- [ ] 정책·기능 지원·실행 상태 등 서로 다른 판단 축의 구분
- [ ] 원문 입력·안내 문구·실측 기록·코드·식별자 보존
- [ ] 실행에 중요한 경고의 본문 표시

## 문장·구조

- [ ] 모든 일반 설명의 명사구 종결과 불릿 적용
- [ ] 개요·상단 참조·패널·접힌 현행 설명의 누락 없음
- [ ] 한 불릿의 한 의미 단위와 실제 상하 관계
- [ ] 조사·호응·부정·금지 의미와 과잉 교정 여부
- [ ] 종결 마침표 제외와 URL·버전·번호의 마침표 보존
- [ ] 필수 용어의 쉬운 뜻·각주 연결, 번호 중복·자기참조 없음
- [ ] 번호·계층·같은 역할의 표 셀 형식 일치
- [ ] 의미계층 기준 빈 문단 2/1/0
- [ ] 자동 목차 3단계, 접힌 기본 문서 이력, 담당자·참조
- [ ] 본문에 불필요한 편집 과정 설명·작업 변경 일지 없음
- [ ] Appendix 전체 접기, 컨테이너 본문 비움, 재귀적 역사 복제 없음

## 도식·연결 자료

- [ ] 미리보기와 실제 편집 가능한 draw.io 원본 존재
- [ ] 접힌 원본 구역과 본문 이미지 참조 확인
- [ ] 그림의 조건·수명·용어·분기와 본문 일치
- [ ] 실제 픽셀의 잘림·겹침·글자·대비 확인
- [ ] 링크한 페이지·절·자료의 실제 존재
- [ ] 시트 핵심 필드·고정 ID·이동 후 집계·필터·선택값 검증
- [ ] 배포 파일과 활성 공유시트의 기준 시점 구분

## 마지막 저장과 보고

- [ ] 마지막 저장 직전 최신 버전 확인
- [ ] 마지막 저장 후 본문·조건·구조·링크·첨부 재조회
- [ ] 초안 일치뿐 아니라 확정 조건의 실제 존재 확인
- [ ] 사용자 수정·담당자·멘션·제목·링크 보존
- [ ] 불일치가 발견되면 최소 수정 후 변경부 재검수

검수 결과는 아래 범위를 분리해서 작성

| 범위 | 확인 내용 |
| --- | --- |
| 내용 검수 | 의미·조건·예외·수치·미결과 출처 대조 |
| 구조 검수 | 제목·불릿·표·목차·여백·각주·접기·링크 |
| 저장 후 재조회 | 최종 저장 버전과 실제 저장 내용 |
| 파일·이미지 미리보기 | 생성 파일 또는 PNG의 표시 |
| 실제 서비스 화면 | 대상 서비스에서의 직접 화면 확인 |
| 실제 기능 시험 | 실제 실행한 경우에 한한 조건·결과 |

- 체크하지 않은 범위를 완료로 합쳐 표현하는 처리 금지
- 저장 내용 검사만으로 실제 화면의 글꼴·색상·접기 동작을 보장하는 표현 금지
- 자동 검사 점수나 문장 유사도만으로 의미 보존·문서 합격·AI 작성 여부를 판정하는 처리 금지
