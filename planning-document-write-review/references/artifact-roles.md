# 도식·시트와 근거의 역할

## 도식

- 본문과 동일한 대상·조건·결과·수명·상태·용어 사용
- 제목·노드·분기·화살표·범례·주석·캡션을 함께 검수
- 흐름 방향, 포함·제외, AND·OR·NOT, 수치와 순서 보존
- 실제 편집 가능한 draw.io 도형·텍스트·연결선으로 원본 구성
- 미리보기 이미지를 draw.io 안에 한 장 붙이는 방식만으로 편집 원본이라고 표현하는 처리 금지
- 문서에는 보이는 미리보기, 원본은 접힌 ‘draw.io 편집 원본’ 구역 안에 연결
- 미리보기의 실제 픽셀에서 잘림·겹침·글자 누락·색상 대비 확인
- 첨부 저장과 본문 참조를 각각 확인, 파일 생성만으로 문서 삽입 완료 선언 금지

## 위키와 검토용 시트

- 위키: 설명·정책·조건·예외·근거·방법론의 기준 위치
- 검토용 시트: 비교할 입력·필수 문맥·판정·지원 전제·처리·사유·안내·검토 의견·합의 중심
- 상세 설명이 위키에 실제 존재하는지 확인한 뒤 시트의 중복 설명을 축소
- 축소 과정에서 행의 필수 문맥·조건·기대 행동까지 삭제하는 처리 금지
- 정책 허용 여부, 현재 단계의 지원, 기술적 보류, 실제 실행 결과의 독립 구분
- 처리 가능이라는 분류를 구현 완료·실행 성공·무조건 허용으로 표현하는 처리 금지
- 현재 미지원·후속 계획·연계 미확인을 정책상 금지로 합치기 금지
- 실제 시험하지 않은 항목은 미실행, 기대값을 실제 결과로 집계하는 처리 금지
- 과거 관찰은 날짜·조건·한계를 유지하며 새 시험과 분리

검토용 시트의 사용성

- 결과별 탭은 같은 열 구조와 고정 ID 유지, 주제는 필터 가능한 별도 열
- 필터 헤더는 1행, 헤더와 필요한 ID 열 고정
- 긴 입력·문맥·사유·안내가 읽히는 줄바꿈·열너비·행높이·글꼴
- 선택값은 드롭다운과 읽을 수 있는 텍스트 제공, 색만으로 뜻을 전달하지 않는 표시
- 의미 있는 상태색과 주제 분류색의 구분
- 행을 다른 탭으로 옮길 때 전체 필드를 함께 이동하고 분류·합의·기대값 정합 확인
- 집계 범위·필터·검증 범위의 시작행과 끝행 명시, 실제 행 이동 후 집계·누락·중복 검증
- 단순한 공통 수식 사용, Google Sheets에서 실제 가져오기를 확인하지 않았다면 호환 완료·네이티브 칩 검증 주장 금지
- 파일 배포본과 사용자가 편집 중인 공유시트의 차이 확인, 최신 편집을 반영하지 않은 파일에는 비교 필요 표시

## 근거와 검증 상태

- 외부 자료: 비교 참고의 적용 범위와 한계 표시
- 개발 문서: 문서에서 확인한 계약과 실제 호출·운영 상태 구분
- 관찰 기록: 실행 조건·수량·날짜·복원 여부·관찰 한계 보존
- 제안: 채택된 제품 결정과 구분
- 검수: 문서의 의미·형식 검수와 실제 제품 기능 검증 구분
- 사실을 확인하지 않은 구체 수치·담당자·지원 기능·통과율 추가 금지
