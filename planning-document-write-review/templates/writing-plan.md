# 작성 설계표

| 항목 | 작성 내용 |
| --- | --- |
| 독자·목적 | 문서를 읽고 이해하거나 결정할 내용 |
| 대상·범위 | 수정할 문서와 하위 자료 |
| 상위의 핵심 | 상위에 남길 결정·흐름·링크 |
| 상세 기준 위치 | 각 고유 기준을 관리할 페이지·절 |
| 원문 유지 | 입력·인용·코드·실측·과거 기록 |
| 의미 보존 | 조건·예외·수치·미결·기능 한계 |
| 최신 사용자 변경 | 보존할 제목·표현·담당 정보·링크 |
| 도식·시트 | 본문과 맞춰야 할 연결 산출물 |
| 최종 검수 범위 | 내용·구조·저장·미리보기·실제 화면 |

필요 없는 행은 제외하고 실제 결정에 필요한 내용만 기록
