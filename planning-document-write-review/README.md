# 문서 작성·검수 스킬

한국어 서비스 기획서의 작성 원칙과 실제 편집·검수 절차를 정리한 재사용 패키지

## 사용

1. ZIP 압축 해제
2. `planning-document-write-review` 폴더 전체를 스킬을 읽는 도구에 제공하거나 해당 도구의 스킬 폴더에 배치
3. `SKILL.md`와 필요한 참조 문서를 함께 읽도록 요청

예시 요청

- 이 스킬 기준으로 기획서의 의미와 서식을 검수해 줘
- 상위에는 핵심만 남기고 상세는 하위 문서로 정리하되 조건·예외·미결을 보존해 줘
- 본문과 도식·검토 시트의 기준을 맞추고 마지막 저장본까지 확인해 줘

이 패키지는 설치나 문서 편집을 자동 실행하지 않으며 특정 도구·사이트에 종속된 실행 스크립트를 포함하지 않음

## 구성

- `SKILL.md`: 적용 범위·핵심 원칙·작업 절차
- `references/`: 문장·서식, 의미 보존, 도식·시트 역할, 최종 검수
- `templates/`: 작성 설계와 변경·검수 기록용 빈 양식
- `manifest.json`: 파일 목록과 SHA-256

## 정리 기준

- 사용자가 제공한 `document-write-review.zip`의 문서 보존·문장·기획서 검수 원칙 참고
- 통합 기준: 의미계층 여백, 상위/상세 역할, Appendix 접기, 편집 원본, 마지막 저장과 실제 화면 구분 기준 반영
- 기존 첨부의 실행 스크립트·외부 검사기 호출·점수 규칙은 포함하지 않음
- 특정 프로젝트의 실제 정책·사람 이름·문서 주소·시험 데이터를 공통 규칙으로 포함하지 않음
- 최신 사용자 지시와 대상 문서의 지정 양식을 이 패키지의 기본값보다 우선 적용
